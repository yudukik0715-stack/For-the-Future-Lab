# For the Future Lab

自分の知識・思考・経験・未来への構想を一つの場所に集約し、相互につなげながら育てていく「自分だけの知識の部屋」。

## デザイン案（`proposals/`）

`proposals/index.html` をブラウザで開くと3案を比べられます。3案は同じデータ（`proposals/shared/store.js`、ブラウザのlocalStorageに保存）を共有しています。

| 案 | コンセプト | 向いている使い方 |
|---|---|---|
| A ラボ・コンソール | 整理された管理画面。数字で進捗が一目でわかる | 進捗管理・継続の見える化を重視 |
| B 知の星図 | 知識を星としてタグでつなぐネットワーク図 | 「相互につながる」発見を重視 |
| C 未来の書斎 | 毎日ひらくノート。日記・問い・未来構想 | 思考と経験を言葉で積み重ねる |

スクリーンショットは `proposals/screenshots/` にあります。

## 完全版 v2（`lab/`）

案をまとめて機能を増やした本番版です。claude.ai のアーティファクトとして公開していて、データはクラウドに保存されます。

- **知識の書庫**：論文・ニュース・百科事典・メモ。要約、要点、ハイライト、メモを残せる。AIで百科事典の項目をつくる、論文を探す、まとめを取り込むことができる
- **画面の中の大学**：学部と講座。チューターが講義ノートを書き、小テストで全問正解すると修了
- **チューター**：いつでも右側から質問できる。「やさしく解説／問いかけで導く／クイズを出す」の3モード。今ひらいている資料をふまえて答える
- **総合研究室・世界観測室**：前の案から引き継ぎ。チューターに研究の批評やデータの読み解きを頼める

`lab/seed.json` は初期データです（アーティファクト外でひらいたときのサンプル表示にも使う）。

## Safari などのブラウザで開ける版（`docs/`）

`docs/` は claude.ai がなくても動く、ふつうのWebページ版です。GitHub Pages で公開すると、iPhone の Safari からURLで開けます（ホーム画面に追加するとアプリのように使える）。

- データはその端末のブラウザに保存されます。別の端末へは「設定 → 書き出す／読み込む」で移せます
- AI機能（チューター・講義・百科事典づくり）は、「設定」に Claude API のキーを入れると使えます。料金は API の従量課金で、Claude の月額プランとは別です
- `docs/vendor/` には Anthropic 公式 SDK（@anthropic-ai/sdk 1.6.0）をブラウザ用にまとめたファイルが入っています

公開手順：GitHub のリポジトリ → Settings → Pages → Source を「Deploy from a branch」、ブランチを選び、フォルダを `/docs` にして Save。
